# numpy-aero

Corso interattivo di **NumPy** per ingegneria aerospaziale.

Python gira direttamente nel browser tramite **Pyodide**: apri la pagina, scegli un esempio e lancia il codice.

## Avvio locale

```bash
cd /home/runner/work/numpy-aero/numpy-aero
python -m http.server 8000
```

Poi apri `http://localhost:8000`.

## Contenuto attuale

- Somma di vettori 3D (velocità relativa)
- Matrice di rotazione attorno all'asse z
- Pressione dinamica su array di velocità
